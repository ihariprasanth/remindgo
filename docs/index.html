v3.0.0 — Customizable UI Engine, macOS & Windows 11 Themes & Instant Startup Latest Release
v3.0.0 Production
  • Full Customization Studio: Built complete theme engine featuring macOS Sonoma Dark & Light, and Windows 11 Mica Dark & Light. Includes 6 dynamic accent colors and 3 typography options (Apple SF Pro, Windows Segoe UI, Developer Mono).
  • Instant Startup (<200ms): Completely removed blocking external font downloads from Chromium initialization. Re-ordered Electron boot sequence so tray and desktop widgets appear instantaneously on Windows startup without waiting for heavy main window creation.
  • Synchronous Local Cache Hydration: Desktop widgets load tasks and LeetCode states directly from synchronous local cache for zero-delay frame-0 rendering.
  • Developer & License Transparency: App Settings prominently showcase Developer: HARIPRASANTH T and Free to Use, Open Source (MIT License) with full architecture diagnostics.
  • Web Showcase Revamp: Completely redesigned landing page featuring an interactive live theme switcher previewing all 4 native styles.
