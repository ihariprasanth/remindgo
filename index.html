Engineered for Precision & Privacy

Everything runs entirely on your local Windows PC without third-party tracking or cloud dependence.

100% Offline SQLite

All tasks, timestamps, and preferences are stored locally in an embedded SQLite binary database. No telemetry, no external accounts.

11 Synthesized Audio Tones

Crystal drop, Zen bowl, marimba alert, cosmic beacon, harp glissando, digital alarm, and radar pulses synthesized entirely offline using the Web Audio API.

LeetCode Sync & Cache

Track solved problem counts (Easy, Medium, Hard), global ranking, and streak. Today's daily challenge can be added as a reminder in one click.

Classical Green Heatmap

Dynamic calendar grid with authentic GitHub classical green intensity blocks for task completions and LeetCode submissions with streak tracking.

Desktop-Locked Widget

Standalone desktop widget with lock/pin toggle that disables dragging when locked, staying cleanly on the desktop background behind active apps.

IST Timezone & Midnight Reset

Calibrated strictly to Indian Standard Time (UTC+05:30) with an automatic 12:00 AM midnight reset that rolls over and starts tracking the next day immediately.
